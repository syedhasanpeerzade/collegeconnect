Print this code and display it on notice boards, canteen tables and department corridors. Students scan it, see every live event with real-time seat counts, and register on the spot. Event posters never go out of date because the QR code never points at a single event.

The destination comes from APP_URL in the server environment. After deploying to a new address, the code regenerates automatically and posters must be reprinted once.

How the campus QR code works

  1. Scan the single permanent CollegeConnect QR code posted around campus.
  2. The code always opens the Events page - it never points to one specific event.
  3. Browse all approved events with live seat availability.
  4. Open an event to check rules, deadline and eligibility.
  5. Register and receive your registration ID instantly.

The QR code is generated from the platform's configured address, so it keeps working all year. When the college updates its web address, the code regenerates automatically - posters only need reprinting when that happens.
